# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussion about the work. Harassment of any kind is not tolerated.

To report a problem, contact the maintainer through their GitHub profile ([@bartawilly](https://github.com/bartawilly)), or open a minimal issue asking to be contacted privately. Security vulnerabilities go through [SECURITY.md](SECURITY.md) instead.
