# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussion about the work. Harassment of any kind is not tolerated.

Report a problem privately through [GitHub's private vulnerability and conduct reporting](https://github.com/bartawilly/qq/security/advisories/new), or by opening a minimal issue asking a maintainer to contact you.
